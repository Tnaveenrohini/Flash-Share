# Flikk Share ⚡ — Made in India 🇮🇳

Fast file transfer app (Quick Share laaga), Flikk family lo moododi.

## Features
- **Phone ↔ Phone** — Wi-Fi Direct (5 GHz try chestundi), internet / router avasaram ledu. QR scan chesthe connect.
- **Phone ↔ PC** — same Wi-Fi (leda phone hotspot) lo unna ye computer browser ayina. Download all (.zip), PC nunchi drag & drop upload.
- **Files, photos/videos, folders (sub-folders tho), apps (APK)**
- **Resume** — madhyalo aagithe "Retry" — aagina chotu nunchi continue
- **History** — pampinavi, vachinavi
- Gallery / file manager lo **Share → Flikk Share**
- English + తెలుగు

Vachina files: `Download/Flikk Share/`

## Use cheyyadam
1. Rendu phones lo app install cheyyandi (Android 10+), Wi-Fi ON.
2. Teesukune phone: **Receive** → QR kanipistundi.
3. Pampe phone: **Send** → files select → **Scan QR & send**.

## Build
Prathi push ki GitHub Actions APK build chesi **Releases** lo `FlikkShare.apk` pedutundi.
